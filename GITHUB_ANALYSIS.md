## Repositórios não selecionados como projetos de destaque

O perfil possui outros repositórios de estudo/exercícios e alguns repositórios vazios. Eles não foram transformados automaticamente em projetos de destaque para evitar apresentar exercícios ou repositórios sem documentação como se fossem projetos principais.

O admin continua permitindo acrescentar novos projetos manualmente.

## Preparado para próximos dados

A tabela `projects` recebeu no projeto uma migração para:
- `image_url`: screenshot/capa do projeto;
- `technologies`: tecnologias usadas no projeto.

Assim, quando screenshots reais forem adicionados, o administrador pode cadastrá-los sem alterar a estrutura visual do jogo.
